# AGENTS.md

Единственный источник правил для агентов в этом репозитории. Внешняя память — `docs/agent/` (архитектура, состояние, решения, журнал сессий).

## Проект

Корпоративный сайт 8Blocks (токеномика, аудит токеномики, консалтинг) с блогом, аудитами, исследованиями, кейсами, событиями и интерактивными инструментами (калькулятор TokenLab, бенчмарки, диагностика).

Стек: Next.js 16 (App Router, Turbopack) · React 19 · TypeScript · SCSS Modules · Mantine · Framer Motion · Payload CMS 3 · PostgreSQL. Язык сайта задаётся при сборке через `NEXT_PUBLIC_LANG` (`ru` | `en`), переключателя языка нет.

## Процесс

- Один агент на сессию. Без ролей, без субагентов, без выбора моделей.
- Работать только в ветке `staging`. В `main` не коммитить и не пушить. Исключение: задачи по новым страницам делаются по разделу «Правила для новых страниц» (отдельная ветка от `staging` и Pull Request).
- Релиз в прод — только через PR `staging` → `main`.
- Деплой ручной, через GitHub Actions → **Deploy to Production** (`.github/workflows/deploy.yml`), параметр `deploy_target`: `all`, `ru`, `en`, `ae`, `staging`.
  - Три прода: RU, EN, AE — собираются из `main`.
  - Staging (EN на `staging.8blocks.io`, RU на `/ru`) — собирается из ветки `staging`.
- После завершения работы — проверка в браузере через Playwright MCP и сверка с макетами через Figma MCP. Если MCP не установлен или не подключён — установить/подключить (Figma MCP требует авторизации владельцем через `/mcp`).
- Перед концом сессии обновить `docs/agent/STATE.md` и добавить строку в `docs/agent/SESSIONS.md`. В `docs/agent/DECISIONS.md` писать только правила, одобренные владельцем.

## Правила кода

- Код по слоям FSD: `src/app` → `src/widgets` → `src/features` → `src/entities` → `src/shared`.
- Тексты — в `src/shared/content/{ru,en}/*.ts`, корневые `src/shared/content/*.ts` выбирают локаль.
- Клиентские компоненты (`'use client'`) не должны импортировать обе локали JSON/контента: выбирать локаль на server-странице и передавать пропсами.
- `src/app/(payload)/admin/importMap.js` генерируется Payload (`generate:importmap`), руками не править.
- Дизайн-система v2: токены и миксины — `src/shared/ds/styles/_tokens.scss`, `_mixins.scss`; витрина — `/staging-docs/design-system`. В вёрстке использовать только токены. Если значение в макете (Figma или HTML из `project/`) не совпадает с токеном — приводить к ближайшему существующему, новых значений не заводить. Уже согласовано: текст 15px → 16px, 13px → 14px; заголовок 48px → 40px (h3). Новые токены — только по решению владельца.
- Новые env-переменные — сразу в `.env.example` с комментарием, секреты деплоя — в `.env-github.example` и `.github/workflows/deploy-site.yml`.

## Правила для новых страниц

Действуют для любой задачи «создать страницу или продукт». Если они расходятся с правилами выше, для таких задач приоритет у этого раздела.

- Каждая задача делается в новой ветке от `staging` с понятным названием, например `page/rwa-tokenomics`.
- В `main` и `master` ничего не пушить и ничего в них не сливать. Результат попадает на сайт только через Pull Request (в `staging`), который проверяет разработчик. Самостоятельно PR не сливать.
- Новые страницы собираются только из существующих компонентов и токенов дизайн-системы. Новые цвета, шрифты, размеры и отступы не придумывать. Если нужного компонента нет, остановиться и спросить.
  - Новые страницы делаются на дизайн-системе v2: страницы в `src/app/(site-v2)`, компоненты из `@/shared/ds` и `src/widgets/ServicePages/blocks`, стили через `@use '@/shared/ds/styles' as *;`. Справочник: `docs/design-system-v2.md`.
- Перед Pull Request запустить сайт локально и показать результат владельцу (скриншоты или адрес в браузере). Без этого PR не открывать.
- Не менять общие компоненты (хедер, футер, кнопки, `src/shared/ds`, `src/shared/ui` и т. п.) без явного согласия владельца: они влияют на весь сайт.
- Не трогать настройки деплоя (`.github/`, `scripts/`), переменные окружения (`.env*`), ключи и платёжные интеграции. Деплой не запускать.
- В текстах для 8Blocks не использовать длинное тире: только запятые, двоеточия, скобки или дефис.
